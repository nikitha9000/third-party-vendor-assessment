


Third-Party Vendor Risk Assessment

Project Overview



This project demonstrates a structured Third-Party Vendor Risk Assessment for Google Workspace, a fictional organizational use case involving the evaluation of a cloud service provider's security and compliance controls.



The assessment evaluates vendor security practices, identifies potential risks, reviews available security evidence, and recommends appropriate risk treatment measures.

Objectives



&#x20;   Develop a third-party vendor security questionnaire.



&#x20;   Evaluate vendor security controls across five domains.



&#x20;   Review publicly available security documentation.



&#x20;   Apply a consistent vendor risk scoring methodology.



&#x20;   Identify security gaps and potential risks.



&#x20;   Produce a vendor risk scorecard and assessment report.



&#x20;   Recommend risk mitigation and monitoring activities.



Assessment Domains



&#x20;   Governance and Compliance



&#x20;   Access Control



&#x20;   Data Protection



&#x20;   Incident Response



&#x20;   Compliance and Assurance



Risk Scoring Methodology

Response	Score

Yes	2

Partial	1

No	0

Tools Used

Scope and Limitations



This is a portfolio simulation based on publicly available information. It does not represent an actual audit, independent certification assessment, or direct security verification of Google Workspace.

Expected Outcome



Demonstrate practical skills in third-party risk management, vendor due diligence, security questionnaire development, evidence review, risk assessment, and GRC reporting.
